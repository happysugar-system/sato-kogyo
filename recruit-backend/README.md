# 佐藤工業・協力大工応募受付（GAS）

このコードは GitHub に保存するだけでは動きません。Google Apps Script に設置・デプロイが必要です。

1. https://script.google.com/home/projects/create を開いて新規プロジェクトを作成
2. `Code.gs` の内容を貼り付け、`setupApplication` を **一度だけ実行**。画面の認証を承認
3. 実行ログに表示される「応募管理シート」を開いて、オーナーが自分であることを確認。一般公開しない
4. 「デプロイ → 新しいデプロイ → ウェブアプリ」から **実行ユーザー：自分 / アクセスできるユーザー：全員** を選ぶ（匿名からの応募に必要）。この公開設定はURLを知る人が送信できることを意味するため、スパム監視が必要
5. 発行された `/exec` URLを `recruit.html` 内の `WEB_APP_URL` の空文字に貼り替える
6. 画面からテスト応募を送り、応募スプレッドシートへの保存とメール通知を確認。テスト行は管理者が削除

注意:
- Googleの実行上限や迷惑投稿で受付できなくなる可能性があります。公開運用ではTurnstile等の検証や送信頻度制限を追加してください。
- 登録された氏名・連絡先を応募者との連絡以外に使わず、管理シートの共有は制限すること。
- HTMLから埋め込み送信した結果は、GASからの確認通知を受信して初めて「受付完了」と表示します。表示が途切れたときは二重送信せず管理シートで確認してください。

## 2026-11-24 受付完了表示の修正

旧版は保存後の iframe メッセージがブラウザに届かないと30秒で確認エラーとなりました。
最新版は doGet?action=status&token=...&callback=... を使い、スプレッドシートの受付ID列を照会して保存成功を検証します。個人情報はGET応答に含めません。

**必須手順:** GitHubの最新 Code.gs を既存GASプロジェクトに反映 → 「デプロイ」→「デプロイを管理」→既存ウェブアプリの編集（鉛筆）→ バージョン「新バージョン」を選択→ デプロイ。既存の /exec URL を維持してください。setupApplication は実行し直さないでください。

古いバージョンのGASでは確認用 doGet が存在しないため、HPのコードだけ更新しても改善しません。1件だけテスト応募し、同じ受付IDで保存され、画面に受付完了表示が出るか確認します。以前のテスト投稿は既に保存されたものとして扱い、再送しないでください。
